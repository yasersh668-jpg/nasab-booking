# مدیریت نوبت نصاب

افزونه‌ی وردپرس برای نصابان دوربین مداربسته و دزدگیر: مشتری از طریق فرم، نوبت نصب ثبت می‌کنه و درخواست‌ها داخل پیشخوان وردپرس مدیریت می‌شن.

## امکانات
- فرم ثبت نوبت نصب برای مشتری
- مدیریت درخواست‌ها در پیشخوان
- اطلاع‌رسانی خودکار با ایمیل
- (جستجوی پیشرفته در لیست درخواست‌ها: اگه کامل شد اضافه کن)

## نصب
1. پوشه‌ی افزونه را در wp-content/plugins کپی کنید.
2. از بخش افزونه‌ها، آن را فعال کنید.

## تکنولوژی
PHP، وردپرس
